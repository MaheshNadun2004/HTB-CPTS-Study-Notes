
# 1.1.4 Post-Engagement

## 📌 Question 01 – Report Designation

### ❓ Question

> What designation do we typically give a report when it is first delivered to a client for a chance to review and comment?

**Answer Format:** One word

### 📖 Walkthrough

Read the **Post-Engagement** module page and identify the designation given to the initial report delivered to a client for review.

### 💡 Answer

<details>
  <summary>Show Answer</summary>

  **DRAFT**

</details>

### 📝 Explanation

A **DRAFT** report is an initial version of a report shared with the client for review and feedback before the final report is prepared.
